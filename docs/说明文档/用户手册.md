## 快速上手（3 分钟）

1. 在主页点击 **项目存储路径** → 选择一个用于集中存放工程的文件夹。
2. 点击 **新建工程** → 填写“工程名称/工程代号/负责人/设备类型” → 创建后自动进入工程。
3. 首次进入若提示新建实验：输入实验名称 → 创建并成为“当前实验”。
4. 进入 **受试管理** → 新建受试者（至少填写姓名/性别/年龄）。
5. 进入 **实验设计** → 添加刺激物（图片/视频/文字/Web/分组）。
6. 进入 **实验录制**：启动设备 → 校准（3/5/9 点）→ 开始录制。
7. 录制完成后进入 **记录列表** → 点击详情回放叠加注视点；需要时可导出叠加后视频。
8. 需要统计时进入 **AOI 分析** 绘制 AOI → 再到 **统计报表** 查看单记录 AOI 指标。
9. 需要导出数据时进入 **数据导出** → 选择记录与字段 → 导出 CSV。

## 安装与启动

本软件通过 Windows 标准安装向导进行安装。

### Windows 安装

1. 双击 `HRT人因研究工具平台-版本号-setup-x64.exe`。
2. 阅读并接受许可协议。
3. 确认安装目录。默认目录为 `C:\HRT`，也可点击“浏览”修改。
4. 点击“安装”，并在 Windows 提示时允许管理员权限。
5. 安装完成后，可通过桌面快捷方式或开始菜单启动软件。

如需卸载，请打开 Windows **设置 → 应用 → 已安装的应用**，找到 **HRT人因研究工具平台** 后选择“卸载”。

### 系统与硬件要求（建议）

- 操作系统：Windows 10/11（发布常用）；macOS 可用于开发/测试环境（以实际发布包为准）。
- 显示器：单屏可用；如需“分屏观察”，建议双显示器。
- 眼动设备：根据设备类型（桌面式/眼镜式）连接硬件与其驱动/服务（由设备厂商提供）。
- 网络：软件通过本地 WebSocket 与 SDK 服务通讯；通常为本机环回或局域网。

### 首次启动必做项

- 在主页设置 **项目存储路径**：用于“自动扫描并加载工程列表”，也决定新建工程的默认落盘位置。
- 在 **设置 → 屏幕配置** 中检查显示器映射（如需分屏）。
- 在 **设置 → 模拟模式** 中可启用“无设备演示”（用于流程演练/培训）。

## 核心概念与数据层级

### 数据层级（最重要的心智模型）

- **工程（Project）**：一个研究/项目的容器，包含多个实验。
- **实验（Experiment）**：同一工程下的一次实验设计与数据集合；实验之间数据相互隔离。
- **实验内数据**（均以“当前实验”为边界）：
  - 受试者（Subjects）
  - 受试者字段定义（Subject Fields）
  - 刺激物/素材（Stimuli）
  - 录制记录（Recordings：视频/眼动 CSV/元数据/标记/分段等）
  - AOI 数据（按记录保存）
  - 自定义标记（录制过程可按键触发）

### “当前实验”的含义

进入某个工程后，界面中展示和编辑的数据都以 **当前实验** 为准。切换当前实验会导致以下内容重新加载：

- 受试者、受试字段
- 刺激物
- 录制记录
- 自定义标记
- AOI/可视化与报表所依赖的数据（跟随记录选择）

## 主页：工程列表（工程库）

### 页面作用

- 管理工程列表
- 快速进入某个工程
- 配置工程统一存储目录（项目存储路径）

### 顶部功能区

#### 搜索

- 按工程名称过滤当前列表（当前实现以名称为主）。

#### 项目存储路径

- 点击选择一个目录作为工程根目录。
- 选择后软件会记住该路径，并自动加载该目录下的工程列表。
- 建议先设项目存储路径，再新建工程，避免工程落盘位置不可控。

#### 导入工程（添加已有工程）

- 从磁盘选择一个已存在的工程目录（需包含 `project.json`）。
- 导入是加入列表引用，不是复制工程。

#### 新建工程

- 填写字段：
  - 工程名称（必填）
  - 工程代号（必填）
  - 负责人（可选）
  - 设备类型：桌面式 / 眼镜式
- 创建后自动进入该工程。

### 工程列表与工程菜单

工程菜单常见项：

- 打开工程
- 在资源文件夹中显示：打开工程目录
- 设置项目显示名称：写回 `project.json`（显示名可与文件夹名不同）
- 从列表中移除：仅移除主页列表项，不删除磁盘文件

## 工程管理（工程信息与实验切换）

### 页面作用

- 维护工程基础信息
- 管理实验（新建/切换/删除）
- 执行工程级操作（备份/导出/删除）

### 工程信息

可编辑字段（以界面为准，通常包含）：

- 工程名称、工程代号、负责人、设备类型、备注/描述

只读信息（常见）：

- 工程 ID、最后更新、当前实验

### 实验管理（当前实验）

#### 切换当前实验

- 通过下拉框切换。
- 切换后会重新加载当前实验的受试者/素材/记录/标记/AOI 等数据。

#### 新建实验

- 输入实验名称即可创建。
- 建议命名规则：`实验_YYYY-MM-DD_批次/条件`，方便回溯。

#### 删除实验（高风险）

- 删除实验会永久删除该实验目录及其全部数据，不可恢复。
- 建议操作前先执行“工程备份/工程导出”。

### 页面底部操作（工程级）

#### 保存工程信息

- 将当前页面工程信息写回工程元数据（`project.json`）。

#### 工程备份 / 工程导出

- 通过系统对话框选择目标目录，生成工程的归档文件（格式以实际实现为准）。
- 建议：
  - 备份用于日常归档（同机保存/移动硬盘）
  - 导出用于交付或迁移到另一台电脑

#### 删除工程（最高风险）

- 删除整个工程目录及其全部数据，不可恢复。
- 与主页“从列表中移除”不同：主页移除不删文件，工程删除会删文件。

## 设置（系统设置弹窗）

入口：工程详情页左侧栏底部 **设置**。

### 1) 系统风格（主题）

- 现代浅色 / 深蓝 / 暗色
- 切换后立即生效

### 2) 时间偏移（注视点与视频对齐）

用途：当注视点叠加在视频上出现“提前/滞后”时，用该值做整体时间对齐。

- 范围：-2000ms ~ +2000ms
- 步长：10ms
- 支持重置

影响范围（全局）：

- 记录详情页注视点叠加
- 数据可视
- AOI 分析
- 统计报表（AOI 计算）

### 3) 采样率设置

用途：用于记录与报表中显示“设置采样率(Hz)”并写入记录元数据。

- 可选：自动 / 30 / 60 / 90 / 120 / 140 / 240 Hz
- 支持重置
- 说明：该值是软件侧配置记录，不等价于设备实际采样率；实际采样率以记录元数据/SDK 输出为准。

### 4) Trigger 配置（UDP）

用途：为录制过程配置 UDP Trigger 外发（常用于与外部设备/程序对时或打点）。

可配置项：

- 启用 Trigger
- 目标 IP
- UDP 发送端口
- UDP 接收端口

Trigger 实际发送需同时满足：

1. 设置中 Trigger 配置已启用并保存
2. 录制页勾选“外发标记”
3. 刺激物或 Group 在“编辑刺激物”中启用 Trigger 并填写 Trigger 标记值
4. 开始录制并进入刺激物播放时机

### 5) 屏幕配置（分屏观察）

用途：配置主试屏与被试屏的显示器映射关系。

- 读取显示器列表
- 选择主试屏、被试屏
- 设置单屏模式
- 保存配置
- 应用并测试

说明：

- 屏幕配置只保存映射关系
- 是否启用分屏由录制页“分屏观察”总开关决定

### 6) 模拟模式（无设备演示）

用途：在没有真实眼动设备时演练刺激物播放与录制流程。

- 启用后会跳过真实设备通信
- 仍可播放刺激物流程
- 若 Trigger 配置开启，UDP Trigger 仍可发送

模拟模式校准：

- 空格：进入下一个校准点
- Esc：退出校准

## 受试管理（受试者字段与自定义标记）

### 受试者列表

- 表格列按字段定义展示。
- 默认内置字段通常包括：姓名、性别、年龄。
- 若存在已激活的自定义标记，列表会额外显示“自定义标记”列（提示该实验可用的标记集合）。

### 新建/编辑/删除受试者

- 新建：填写姓名/性别/年龄与全部自定义字段。
- 编辑：同新建。
- 删除：
  - 删除受试者条目本身
  - 通常不自动删除已产生的录制文件（避免误删数据），需在记录列表按记录维度删除

### 字段管理（受试者字段）

- 查看所有字段
- 新增自定义字段
- 删除自定义字段（内置字段不可删除）

建议：

- 正式采集前先确定字段集合（避免后期补字段导致导出表头不一致）。
- 字段命名建议避免频繁变更（利于后续统计脚本稳定）。

### 自定义标记（录制键盘标记）

入口：受试管理页顶部 **自定义标记**。

每个标记可配置：

- 名称、描述、颜色
- 类型：瞬时 / 持续
- 按键
- 是否激活

录制时行为：

- 瞬时标记：按一次记录一次
- 持续标记：按下开始，松开结束；按住期间会持续写入（用于表示某段状态持续存在）

## 实验设计（刺激物/素材库）

### 支持的刺激物类型

1. 图片（文件导入，可多选）
2. 视频（文件导入，可多选）
3. 文字（直接输入）
4. Web 网址（输入 URL）
5. 分组（Group：一个容器卡片，内部再添加素材）

### 添加刺激物（导入/创建）

#### 图片/视频

- 通过文件选择器导入
- 支持多选

#### 文字

- 名称（可选）：为空时通常取首行文字作为默认名称
- 文字内容：支持多行

#### Web 网址

- 名称（可选）
- 网址：若缺少 `http://` 或 `https://`，软件会自动补全为 `https://`

#### 分组（Group）

- 创建一个组卡片
- 进入 Group 后再添加素材写入该 Group

### 素材库展示与编号

- 根目录视图：显示普通素材 + Group 卡片
- Group 内视图：显示组内素材
- 支持拖拽交换顺序
- 组内编号通常为“组编号-组内序号”

### 编辑刺激物（关键参数解释）

#### 通用项

- 名称
- 固定时间（秒）：该刺激物播放的固定时长；未设置时默认按 5 秒处理
- 激活：不激活的素材不会进入录制播放序列
- 点击结束 / 按键结束：决定该刺激物是否响应录制页的全局结束开关

#### 非 Group 素材常见项

- 背景颜色
- 随机播放（素材级随机）
- Trigger 开关 + Trigger 标记值（数值）

#### 文字素材额外项

- 字体颜色、文字大小、背景颜色

#### Group 素材额外项（播放模式）

常见模式（名称以界面为准）：

- 全部展示-顺序 / 全部展示-随机
- 随机播放（抽样）
- 重复播放（重复次数）

对应参数：

- 抽样数量
- 重复次数

Trigger 说明：

- Trigger 标记值要求为合法数字
- 当 Group 启用 Trigger 时：会在播放第一个组内素材之前发送 Group Trigger

## 实验录制（连接设备-校准-播放-生成记录）

### 页面作用

- 启动/停止设备
- 执行校准
- 选择受试者与录制参数
- 播放刺激物序列并生成录制记录

### 自动连接行为

进入录制页后，软件会自动尝试连接图像流、命令 WebSocket、眼动数据 WebSocket。离开录制页后会自动关闭连接并停止设备监控流程。

### 推荐录制流程（标准 SOP）

1. 确认当前实验正确（工程管理页可切换）
2. 在受试管理中完成受试者信息
3. 在实验设计中准备刺激物并确认激活/顺序/时长/Trigger
4. 进入录制页选择受试者
5. 点击“启动设备”
6. 点击“开始校准”（3/5/9 点）
7. 校准完成后点击“开始录制”
8. 播放完成自动结束，或按规则提前结束
9. 在记录列表核对新生成记录（时长/有效率/采样率等）

### 校准说明

- 普通模式：向设备发送真实校准命令，返回左右眼分数
- 分屏校准：
  - 录制页勾选“分屏观察”
  - 设置→屏幕配置已配置被试屏
  - 校准时软件尝试在被试屏显示校准画面
- 模拟模式：空格推进校准点，Esc 退出

### 录制选项（右侧面板常见项）

- 随机播放：对播放序列做整体随机化（与素材级随机叠加时需注意口径）
- 分屏观察：主试屏监控，被试屏展示刺激物/校准
- 外发标记：允许 Trigger 生效（需配合设置与刺激物 Trigger）
- 隐藏注视点：仅隐藏显示，不影响数据采集
- 记录鼠标：将鼠标位置写入数据（以实际实现为准）
- 点击结束 / 按键结束：录制级全局结束开关
- 眼图显示/保存眼图数据/保存眼图校准：用于记录额外数据（以界面实现为准）

### 点击结束 / 按键结束（全局与素材联动规则）

- 录制页“点击结束/按键结束”是全局开关
- 若全局开关关闭：点击/按键不参与结束逻辑
- 若全局开关打开：
  - 当前刺激物也勾选了同项：执行“切到下一个刺激物”
  - 当前刺激物未勾选同项：直接结束整场录制
- 当前按键结束通常只响应 `Esc`

### 自定义标记（录制中的按键打点）

- 录制过程中，当前实验中已激活的自定义标记可通过按键触发
- 瞬时/持续的行为见 [受试管理（受试者字段与自定义标记）](#受试管理受试者字段与自定义标记)

### Trigger 发送时机

- 普通刺激物：该刺激物开始播放时发送
- Group：在第一个组内素材之前发送 Group Trigger

## 记录列表与记录详情（回放/叠加/导出视频）

### 记录列表

用途：查看当前实验下全部录制记录。

常见列：

1. 记录名
2. 受试者
3. 录制时间
4. 校准得分(左:右)
5. 采样率(Hz) / 设置采样率(Hz)
6. 有效率(%)
7. 时长(s)
8. 操作（详情/删除/导出等）

常见操作：

- 详情：进入记录详情页
- 删除：删除该记录关联的录制文件，不可恢复

## AOI 分析（手工 AOI / Gridded AOI）

### 页面作用

在单条记录上绘制 AOI，并计算 AOI 统计数据。

支持：

- 手工 AOI（矩形/椭圆/多边形）
- Gridded AOI（网格统计）

### 记录与刺激物选择

- 右侧选择当前记录
- 可按刺激物筛选（影响统计与时间范围，不替换背景视频）

### 手工 AOI 绘制

工具：

1. 矩形：按下拖拽绘制，松开完成
2. 椭圆：同矩形
3. 多边形：依次点选顶点；接近起点闭合或右键结束

AOI 列表（非网格模式）：

- 重命名
- 颜色切换
- 显示/隐藏
- 删除

AOI 显示设置（以界面为准）：

- 显示 AOI 名称
- 不透明度
- 边框粗细
- 字体大小

### AOI 指标（统计数据区）

可按“选择指标”决定显示哪些列；常见指标包括（以界面为准）：

- 注视次数、首次注视前时长/次数、首次注视时长、总/平均/最大注视时长
- 注视人数
- 总/首次/平均停留时长、访问次数、回看次数/人数
- 平均瞳孔直径(mm)

说明：

- AOI 统计会跟随当前时间偏移与播放范围变化
- 时间轴提供独立的“全局统计范围”和“当前 AOI 统计范围”两条轨道；“拖选用途”开关决定新范围写入哪一条。两类范围均可分别激活/未激活，只有激活范围参与对应统计；全局范围状态随记录保存。
- 已设置范围的 AOI 会严格只统计处于“激活”状态的时间区间并集；范围外或“未激活”的范围不参与该 AOI 的注视、停留、眨眼等统计。每段默认激活，可直接点击范围中央的“激活/未激活”小按钮切换，也可在 AOI 列表中切换；每段可在时间轴中右键后单独清除。
- 自定义时间范围按 AOI 保存，不会影响其他 AOI，也不会新建全局时间轴分段。
- AOI 数据按记录保存（不是按工程/实验全局一份）

### Gridded AOI（网格 AOI）

开启后进入网格统计模式（与手工 AOI 不同界面编辑）。

可调项（常见）：

- 指标选择
- 注视点与视频时间对齐(ms)
- 栅格行列数（1-20）与快速预设
- 蒙版透明度、字体大小
- 显示数据/标尺

## 数据文件与目录结构（重要）

本节用于你在磁盘侧核对数据是否真的保存成功，以及做备份/迁移/对接统计脚本时定位文件。

### 工程目录（Project）

工程目录下至少包含：

- `project.json`：工程元数据
- `.config/experiments.json`：实验索引
- `experiments/`：实验目录集合

### 实验目录（Experiment）

每个实验目录下会创建模块目录（以当前实现为准）：

- `subjects/`：受试者与字段定义等
- `stimuli/`：刺激物文件与 `stimuli.json`
- `recordings/`：录制视频、眼动 CSV、元数据、标记、分段等
- `visualization/`：AOI 等可视化数据
- `reports/`：报表相关（若使用）
- `exports/`：导出相关（若使用）
- `experiment.json`：实验元数据

### 录制文件命名（常见）

在 `recordings/` 下常见会看到：

- `受试者名_YYYYMMDD_HHMMSS.mp4`
- `受试者名_YYYYMMDD_HHMMSS.eye_samples.csv`（眼动采样数据）
- `xxx.meta.json`（记录元数据）
- `xxx.markers.json`（标记）
- `xxx.segments.json`（时间分段）

华弘 ET28 / ET10 的录制使用 `huahong_<12位标识>.mp4`、同名 `.csv` 和 `.meta.json`，原始附档保存在同名 `.pupil` 目录。实验记录页根据实际文件及产品元数据加载这些记录，无需手动改成日期文件名。保留完整文件组；缺少视频或 CSV 时显示为部分记录。此类旧记录没有录制开始日期字段时，列表日期使用文件时间。

### AOI 数据保存位置（常见）

- AOI 数据通常保存为：`visualization/aoi.json`
- 结构一般为按 recordId 索引保存，因此同一实验内多个记录的 AOI 可能集中写入同一文件。

## 常见问题（FAQ）与排错

### 1) 主页工程列表为空/打不开工程

- 检查是否已设置正确的“项目存储路径”
- 若工程是从别处拷贝过来：先确认工程目录内存在 `project.json`，再用“导入工程/添加工程”加入列表

### 2) 开始录制提示“没有刺激物可播放”

- 进入“实验设计”检查是否已添加素材
- 确认素材处于“激活”状态（未激活不会进入播放序列）
- 若只有 Group：确认 Group 内部有素材且满足抽样/重复等规则

### 3) 开始录制提示“请先新建并选择受试者”

- 在“受试管理”新建受试者
- 回到录制页选择受试者

### 4) 分屏观察无法打开被试屏窗口

- 检查“设置 → 屏幕配置”是否选择了被试屏
- 检查系统是否识别到第二显示器（显示器已连接且在系统里启用扩展/镜像模式）
- 录制页必须勾选“分屏观察”才会实际启用

### 5) Trigger 不发送

按链路逐项排查：

1. 设置 → Trigger 配置：已启用并保存；IP/端口合法
2. 录制页：已勾选“外发标记”
3. 当前刺激物或 Group：已启用 Trigger 且标记值为数字
4. 播放是否真的开始（Trigger 在播放时机触发）

### 6) AOI/报表为空

- AOI 页：需先选择记录，并绘制/保存 AOI（或使用网格 AOI）
- 报表页：需要当前记录同时具备眼动 CSV 数据与已保存 AOI 数据
